Gift voucher test page

This page exercises the in-house voucher flow end to end: Stripe Checkout → voucher code generation → email delivery → admin redemption. The live GiftUp widget is untouched elsewhere on the site until this is signed off.

⚠️ Live keys — real charges. Payments here are real and emails send for real. Test with your own email address and an amount you're happy to spend (£10 minimum), then refund yourself in the Stripe dashboard.

1. Generic voucher

No tour context — the buyer picks any amount. This is what opens from the header, footer and gift voucher page.

2. Prefilled from a tour page

These carry the tour's per-person price and name, so the amount is prefilled and the message pre-written recommending that tour. The buyer can still edit both.

What to check

  • Amount prefills from the tour, and can be edited.
  • The +/− stepper moves the total; each voucher gets its own code.
  • "Someone else" vs "Myself" shows/hides the recipient fields.
  • The message is pre-written for the tour, and stays put once you edit it.
  • Amounts under £10 are rejected.
  • After paying: voucher email to the recipient, receipt to the buyer.
  • The code appears in the admin — try a partial then full redemption.
